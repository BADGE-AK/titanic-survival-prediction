# Titanic Survival Prediction

## Project Overview

This project predicts whether a passenger survived the Titanic disaster using Machine Learning.

The project follows a professional folder structure by separating data loading, preprocessing, visualization, model training, and utility functions into different Python modules.

---

## Project Structure

```
Titanic-Project/
│
├── data/
├── notebooks/
├── src/
│   ├── load_data.py
│   ├── preprocessing.py
│   ├── visualization.py
│   ├── model.py
│   ├── utils.py
│   └── __init__.py
│
├── README.md
├── requirements.txt
└── .gitignore
```
